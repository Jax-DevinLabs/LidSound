# 隐私说明

**简短版：LidSound 不收集你的任何数据。**

本文说明我们到底通过网络发送了什么，以及为什么不收集更多。

---

## 我们收集什么

### 默认情况下：什么都不收集

LidSound 没有账号系统，没有登录，没有注册。

我们**不收集**：

- ❌ 你的姓名、邮箱、手机号
- ❌ 你的硬件型号、操作系统版本
- ❌ 你的使用记录、开了多少次、用了哪段音效
- ❌ 任何能识别「你是谁」的信息
- ❌ 任何能识别「你做了什么」的信息

---

## 唯一的网络请求

### 检查更新（仅安装版）

安装版会访问 GitHub 检查有没有新版本。

**发送的内容：**

| 项 | 说明 |
|---|---|
| 请求目标 | `api.github.com`（GitHub 的公开 API） |
| 请求内容 | **只有仓库名**（`Jax-DevinLabs/LidSound`） |
| 携带信息 | 无。不含任何设备标识、用户 ID、IP 之外的任何数据 |

**我们看不到谁在检查更新**——GitHub 的 API 日志只有 IP 和请求路径，而 IP 是网络层信息，我们无法访问也未尝试访问。

如果你不想有这次请求，用**免安装版**——它不做更新检查，全程零网络请求。

### 下载更新

发现新版本时，会从 GitHub 下载安装包。这是普通的 HTTPS 下载，和浏览器下载文件没区别。

## 本地存了什么

全部在你自己电脑上，我们拿不到：

| 文件 | 内容 | 位置 |
|---|---|---|
| `settings.json` | 你的开关状态、选了哪段音效 | 安装版：`%LOCALAPPDATA%\com.jaxdevinlabs.lidsound\current\`<br>免安装版：`<解压目录>\` |
| `lidsound.log` | 本地日志：开盖事件、播放记录、错误信息 | 同上，`logs\` 子目录 |

> 托盘菜单「**打开日志目录**」可以直接打开，不用自己找路径。

**日志里有什么：**

- 时间戳
- 开盖事件
- 音效 ID（`keyboard-mechanical` 这种标识符，不是文件路径）
- 错误类型和异常消息

**日志里没有什么：**

- 没有麦克风录音（**这个软件不录音，也不检测敲击**）
- 没有键盘输入
- 没有屏幕内容
- 没有窗口标题
- 没有其他程序的任何信息

日志文件超过 2MB 会自动截断，不无限增长。

## 我们不做什么

明确承诺以下几件事，我们**不会做**，将来也不会做：

- ❌ 不做用户行为分析
- ❌ 不做崩溃上报（哪怕崩溃也只写到本地日志）
- ❌ 不采集设备指纹（见下方关于机器指纹的说明）
- ❌ 不做 A/B 测试分流
- ❌ 不联任何第三方广告或统计 SDK
- ❌ 不读取其他文件（除了它自己目录下的配置和素材）

### 关于机器指纹（自定义音效授权）

解锁「上传自己的音频」需要兑换码，兑换码绑定机器。由此会用到一段**机器指纹**：

- 由程序**在你的电脑上本地生成**（取 Windows 机器 GUID、主板/BIOS、CPU 的序列号做哈希），
- 程序**不会上传、不会记录、不会发送**它——它只显示在授权窗口里，
- **仅当你主动点「复制完整指纹」发给卖家时**，它才会离开你的设备，
- 它只用来生成只对你这台机器有效的授权，不用于任何其他目的。

如果将来某天需要收集数据（比如做崩溃统计方便修 bug），
**会先在这里写清楚收集什么、为什么、怎么关** —— 而不是悄悄加上去。

## 第三方组件

LidSound 使用了以下开源组件。它们都在你的电脑上本地运行，**不产生任何网络请求**：

| 组件 | 用途 | 许可 |
|---|---|---|
| [NAudio](https://github.com/naudio/NAudio) | 音频播放 | MIT |
| [Velopack](https://velopack.io) | 安装与自动更新 | MIT |
| .NET Runtime | 运行环境 | MIT |

本项目自身也用 MIT 许可。
