## 安装

### 推荐：安装版

1. 下载 [`LidSound-Setup.exe`](https://github.com/Jax-DevinLabs/LidSound/releases/latest)
2. 双击运行
3. 如果弹出「Windows 保护了你的电脑」→ 点 **「更多信息」→「仍要运行」**
4. 装完开始菜单会出现 LidSound

**为什么会有那个提示？**
LidSound 没有购买代码签名证书（一张约 $70/年）。没有证书的程序，Windows 都会这样提醒——
不只针对 LidSound，你装任何新工具都可能看到。点「仍要运行」即可。

### 备用：免安装版

1. 下载 `LidSound-Portable.zip`
2. 解压到任意目录
3. 双击 `LidSound.exe`

**区别**：免安装版**不会自动更新**。有新版本要手动重新下载。

> 两种版本都不需要另外安装 .NET 运行环境，运行环境已经打包进去了。

## 第一次使用

装完之后**什么都不用做**，软件已经在后台运行了。

下次你打开笔记本上盖时，就会听到一声音效。

想换音效？托盘图标 → 右键 → 「打开设置」。

## 托盘菜单

在任务栏右下角找到 LidSound 图标（闪电）。找不到的话点任务栏上的 **「^」** 展开隐藏图标。

| 菜单项 | 作用 |
|---|---|
| **停用/启用开盖音效** | 临时关掉/打开，不用进设置 |
| 当前音效 | 显示现在用的是哪一段（灰色，不可点） |
| **打开设置** | 打开主窗口。也可以**双击托盘图标** |
| **退出** | 完全退出程序 |

> **点窗口右上角的「✕」不会退出程序**，只是隐藏窗口，托盘还在跑。
> 想真正关闭必须用托盘菜单的「退出」。
>
> 这是特意设计的——常驻工具如果点× 就消失，用户会以为它崩了，然后去装卸载包。

### 设置窗口能做什么

| 控件 | 作用 |
|---|---|
| **开盖音效** | 总开关。关掉后完全不触发 |
| **音效** | 下拉选择用哪一段 |
| **▶ 试听** | 听一下当前选中的音效 |
| **⟲ 恢复默认** | 一切回到初始状态。**出问题时先用这个** |

**设置立即生效**，不用重启，也不用点保存。

## 换成自己的音效

不需要重新安装，改一个配置文件就行。

### 步骤

**1. 找到 assets 目录**

| 版本 | 路径 |
|---|---|
| 安装版 | `%LOCALAPPDATA%\com.jaxdevinlabs.lidsound\current\assets` |
| 免安装版 | 就是你解压出来的那个目录下的 `assets` |

> 按 `Win + R`，粘贴上面那行路径，回车就能打开。

**2. 准备音频文件**

要求：**`.wav` 格式，44100Hz，单声道，16 位**。

- 时长建议 **0.3–1.5 秒**。太长会显得吵，太短听不清。
- 文件别太大，1MB 以内比较合适。

> 用手机录一段也行。不确定格式的话，Windows 自带的「录音机」录的 m4a 需要转换，
> 免费转换工具：[Audacity](https://www.audacityteam.org/)（开源）。

**3. 把文件放进 `assets\sounds\`**

**4. 编辑 `manifest.json`**

用记事本或 VS Code 打开，在 `assets` 数组里加一条：

```json
{
  "id": "my-sound",
  "displayName": "我的音效",
  "type": "sound",
  "action": "playSound",
  "file": "sounds/my-sound.wav",
  "durationMs": 1000
}
```

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识，不能和现有的重复。**不要用空格** |
| `displayName` | 下拉框里显示的名字 |
| `file` | 相对 `assets` 的路径，注意用 `/` 而不是 `\` |
| `durationMs` | 实际时长（毫秒）。只是个记录，不影响播放 |

想让它成为默认，把原来那条的 `"isDefault": true` 删掉，给新的加上。

**5. 重启软件**

托盘菜单 → 「退出」，然后重新打开。下拉框里就有你的音效了。

### 常见失败

| 现象 | 原因 |
|---|---|
| 下拉框里没有你的音效 | `id` 重复了，或者 JSON 格式错了（少逗号、引号不配对） |
| 选了但没声音 | 文件路径不对，或格式不是 wav。用 `文件资源管理器`确认文件真的在那个位置 |
| 播放很慢 | 文件太大，压缩一下 |

## 常见问题

**Q：打开上盖没声音**

按顺序排查：

1. 托盘图标右键，确认「开盖音效」是启用状态
2. 设置窗口里确认总开关是开的
3. 换个音效试试——可能只是这段音效文件有问题
4. 看日志：`%LOCALAPPDATA%\com.jaxdevinlabs.lidsound\current\logs\lidsound.log`

日志里这几种情况：

| 日志内容 | 含义 |
|---|---|
| `开盖监听已启动` | 检测正常，那问题在音效或开关上 |
| `开盖监听不可用` | **你的机型固件不上报开盖状态**，软件无法检测。软件本身没问题 |
| `音效播放失败（已静默）` | 音频设备被占用，或音效文件损坏 |

`开盖监听不可用` 这种情况请提 issue 告诉我们你的机型，我们补适配。

**Q：延迟大**
约 100ms 是正常的，这是 Windows 音频设备的启动开销。压不下去。

**Q：占内存吗**
约 260 MB（包含打包的 .NET 运行时）。CPU 空闲时几乎不占用——
它只在开盖那一瞬间动作。

**Q：合盖为什么不响**
只在你**打开**上盖时触发。合盖时笔记本可能已经进入待机，来不及播。

**Q：能开机就响吗**
做不到。UEFI 规范只支持单张静态图片，没有音频通道。这是硬件层面的限制。

**Q：会自动更新吗**
安装版会，后台静默检查。免安装版不会。

**Q：会联网吗**
自动更新会访问 GitHub 检查新版本。除此之外**完全离线**，见[隐私说明](隐私说明.md)。

## 卸载

**方法一**（推荐）
Windows 设置 → 应用 → 已安装的应用 → 找到 LidSound → 卸载

**方法二**
运行安装包，选择「卸载」

**残留说明**

卸载后会留下一个文件夹：
```
%LOCALAPPDATA%\com.jaxdevinlabs.lidsound
```
里面是更新器的自保留文件和日志。想彻底清理可以手动删除。

你的设置和音效都在这个目录下——**卸载不会自动删**，重装后设置还在。
